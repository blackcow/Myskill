# 测试用例

本目录按信息来源保存测试输入、测试目的和已生成的样例输出。它和 `03_归档样例` 的区别是：这里用于验证采集方案效果，允许保留多组对比用例；`03_归档样例` 更接近长期归档资产的示例库。

## 目录

| 编号 | 来源 | 内容 |
| --- | --- | --- |
| `01_公开网页归档` | 公开普通网页 | 多种网页类型的 Markdown 归档输出。 |
| `02_youtube逐字稿` | YouTube transcript/caption | 每个视频一个输出目录，包含阅读主文件、分组 JSON、原始字幕和 metadata。 |
| `03_微信公众号文章` | 微信公众号文章 | 公众号文章归档测试输出。 |
| `04_论文PDF归档` | 论文 PDF / arXiv | 每篇论文一个输出目录，包含阅读主文件、结构化 JSON、原始 PDF 和 metadata。 |
| `05_微信视频号视频` | 微信视频号视频 | 每个视频一个输出目录，包含视频阅读主文件、字幕状态、公开接口响应、封面资源和 metadata；用户提供媒体后的 ASR 冒烟测试单独保留。 |

## 使用方式

每个子目录都包含自己的 `README.md` 和 `outputs/`。回归测试时优先检查：

1. 输出文件是否完整。
2. 正文文件是否以必要 YAML frontmatter 开头，完整抓取元数据是否进入 `metadata.json` 或来源对应 JSON。
3. 正文是否缺失、乱码、混入导航噪声或误判 speaker。
4. 新实现是否比对应历史输出更稳定。
