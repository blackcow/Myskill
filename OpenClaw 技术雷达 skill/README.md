# OpenClaw 技术雷达 Agent

## 项目定位

这是一个面向个人技术成长的技术雷达 Agent 设计项目。

它的目标不是收集更多信息，而是在海量技术信息中帮助用户：

- 过滤噪声。
- 分配有限注意力。
- 辅助理解关键技术。
- 形成个人技术判断。
- 沉淀长期可复用的认知资产。

## 当前核心结论

技术雷达 Agent 的核心链路是：

```text
信息输入
-> 来源识别
-> 内容抓取 / 手工补充
-> 方向分类
-> 重要性分级
-> 注意力投入建议
-> 技术卡片
-> 认知资产沉淀
```

当前优先级：

- 优先做好信息重要性判断。
- 优先做好 L0-L4 注意力分级。
- 优先做好个人技术卡片和认知资产沉淀。
- 周报、汇报、团队材料暂不作为核心目标。

## 推荐实现形态

不要只做成一个 skill，也不要一开始做成完整独立产品。

建议形态：

```text
Tech Radar Skill
  -> 定义判断流程、分级规则、卡片格式、资产沉淀协议

Source Tools
  -> 抓取和解析微信公众号、公开网页、X / Twitter、arXiv、GitHub、YouTube transcript

Asset Wiki / Repo
  -> 保存 raw source、radar cards、认知资产、index、log

OpenClaw / Hermes Workflow
  -> 编排 skill、工具服务和资产库，形成可重复执行的 Agent 流程
```

一句话：

> skill 是脑子，工具是手，资产库是长期记忆，OpenClaw / Hermes workflow 是执行编排。
