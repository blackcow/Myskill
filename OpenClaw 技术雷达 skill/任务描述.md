# 任务描述入口

本项目用于设计一个基于 OpenClaw / Hermes 类 Agent 的“技术雷达 Agent”。

当前文档已经拆成渐进式阅读结构，避免把所有信息放在一个大 Markdown 里。

## 一句话定位

技术雷达 Agent 不是收藏夹，也不是摘要工具，而是：

> 个人技术信息过滤、注意力分配与认知资产沉淀 Agent。

## 当前共识

- 核心目标是提升个人技术理解与认知效率，而不是生成周报或汇报材料。
- 第一价值是分配注意力：判断哪些信息应该忽略、记录、短读、深读或沉淀为资产。
- 信息过滤在前，资产沉淀在后。
- 合适形态不是单一 skill，而是 `skill + 工具服务 + Markdown 资产库 + OpenClaw / Hermes workflow` 的组合。
