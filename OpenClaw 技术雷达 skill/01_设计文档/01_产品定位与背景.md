# 01 产品定位与背景

## 什么时候读

当需要重新确认“为什么做这个能力”“它不是普通知识库”时，读这篇。

## 一句话定位

技术雷达 Agent 是：

> 个人技术信息过滤、注意力分配与认知资产沉淀 Agent。

它不是：

- 普通知识库。
- 收藏夹。
- 摘要工具。
- 周报生成器。
- 泛 AI 热点聚合器。

## 核心目标

不是收集更多资料，而是：

- 降低技术信息判断成本。
- 减少无效阅读和认知负担。
- 帮助用户在信息洪流中分配有限注意力。
- 把高价值技术信息转成可复用、可沉淀的个人技术资产和认知资产。

## 用户背景

- 用户当前在公司做 ToB Agent / 企业智能体平台方向。
- 用户是计算机博士，对大模型应用赛道非常认可，认为这是值得持续投入和沉淀的长期方向。
- 用户曾训练过 CV 方向的 Transformer 模型，虽然不是大模型训练经历，但对模型结构、训练过程、模型能力边界和应用落地有相对深入的理解。
- 用户对 Agent 和大模型应用底层原理理解较深，因此在工作中能做出更高质量的东西，但也因此被安排了更多任务。
- 用户希望做有沉淀、有复用、有体系建设价值的工作，而不是长期被消耗在重复交付和体力劳动中。

## 当前痛点

- Agent 和大模型技术迭代极快。
- 外部技术压力会直接传导到工作中。
- 用户本来喜欢看最新技术，但技术信息和工作压力绑定后，非工作时间看到相关内容会开始反感。
- 很多技术内容被收藏，但没有时间阅读、理解和判断。
- 收藏逐渐变成认知债务，而不是知识资产。
- 不同信息的重要性不清楚，容易被热点和信息流牵引，分散个人注意力。

## 设计方向

这个能力的关键不是“帮用户多看”，而是“帮用户少看但看得更准”。

它需要先回答：

- 这条信息是否值得看？
- 它值得投入多少注意力？
- 它对当前认知结构有什么增量？
- 它是否值得沉淀为长期认知资产？
